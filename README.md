# مستر شوقى — Mr. Shawky | الامتياز فى الرياضيات

ألعاب تفاعلية لمادة الرياضيات — الصف الأول الثانوى (الفصل الدراسى الأول).
للتواصل: 01220140902

- `index.html` : الصفحة الرئيسية (الدروس)
- `game.html?l=1` : الدرس الأول — مقدمة عن الأعداد المركبة
- `game.html?l=2` : الدرس الثانى — تحديد نوع جذرى المعادلة التربيعية
- `game.html?l=3` : الدرس الثالث — الزاوية الموجهة
- `game.html?l=4` : الدرس الرابع — تشابه المضلعات
- `game.html?l=5` : الدرس الخامس — تشابه المثلثات
- `data/` : أسئلة كل درس — الألعاب فى كل الدروس: تسجيل الأهداف، شد الحبل، صح أم خطأ، التوصيل، الفقاعات، التنشين (6 × 15 سؤالًا، بدون وقت محدد)
- `img/` : أشكال الأسئلة المقتطعة من الكتاب المدرسى
- `assets/` : التصميم ومحرك الألعاب واللوجو (يعمل بدون إنترنت عدا الخط)
